# The NorthCel writing guide

This guide teaches the language in order. Pages 1–16 are self-contained: syntax,
what it means, a complete `.ncel` file, the rendered image of that file, one
deliberate mistake with the **real** diagnostic, and the command that reproduces
it. Every snippet and every image on these pages is generated by the docs build
from the real `northcel` tool (see [Machine-checked docs](../README.md#machine-checked-docs)).
Runnable files use `ncel` fences; deliberate failures use marked `text` fences
and still have their exact diagnostics checked.

New to NorthCel? Read 1–3, then jump to the construct you need. Writing an
animation? Read 8–10 and 14, then the [editable-drawing method](17-editable-drawings.md)
for addressable edits. Writing an AI agent prompt? Read
[the agent guide](../agent-guide.md) after 1–3.

The guide targets **tools 0.7.2 / spec 0.6.0-draft**. Page 17 teaches the
addressable-edit method with five worked illustrations, not templates. The
[current specification](../spec/SPEC-0.6.0-draft.md) defines the exact contract.
